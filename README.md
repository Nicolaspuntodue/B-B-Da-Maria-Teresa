# B&B da Maria Teresa · demo homepage

Demo concept della homepage scroll-driven per il B&B da Maria Teresa (Via Sorgimpiano 2, Maratea, PZ) e il ristorante Da Mamma e Papà.

- Vite + three.js (finestra 3D con le persiane che si aprono sul golfo, luce reale di Maratea: alba, giorno, tramonto, notte) + GSAP ScrollTrigger + Lenis
- Foto delle camere reali (Booking), pulite; panorama, pasta e terrazza serale generati con Higgsfield; foto di Maratea da Wikimedia Commons (crediti nel footer)
- Prezzi delle camere e del menu di esempio, da confermare con la famiglia

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # tariffe + alba/tramonto
npm run build   # output in dist/
```
